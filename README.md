# 🧩 Decode COA Forum

**Decode COA Forum** is a community-driven online platform designed for collaborative discussions, Q&A, and knowledge sharing around Computer Organization & Architecture (COA) concepts. Built with **React (Vite + TypeScript)** and powered by **Supabase**, this forum allows users to sign up, post questions, comment, and engage in academic discussions.

---

## 🚀 Features

- 🔐 **User Authentication** (Sign Up, Login, Logout)
- 💬 **Forum-style posts and comments**
- 🧠 **Role-based metadata** for users (student, mentor, etc.)
- ⚡️ **Realtime** updates via Supabase
- 📱 **Responsive** and fast UI with React + Vite

---

## 🛠 Tech Stack

- **Frontend**: React (Vite, TypeScript)
- **Backend**: Supabase (PostgreSQL, Auth, Realtime)
- **State**: React Context API / Hooks
- **Styling**: TailwindCSS (or your preferred styling)
